# KB-010 · Proceso de onboarding (nuevas incorporaciones)

**Categoría:** RRHH / Onboarding

## Antes del primer día

RRHH enviará al nuevo empleado un correo con:
- Enlace para activar la cuenta corporativa.
- Guía de bienvenida en PDF.
- Hora y punto de encuentro el primer día.

## Primer día

| Hora | Actividad |
|------|-----------|
| 09:00 | Recepción en recepción, entrega de tarjeta de acceso |
| 09:30 | Firma de contrato y documentación RRHH |
| 10:00 | Entrega de equipo informático y configuración inicial |
| 11:00 | Tour por las instalaciones |
| 11:30 | Presentación con el equipo y manager |
| 12:30 | Comida de bienvenida con el equipo |

## Primera semana

- Acceso a todos los sistemas corporativos (ver **KB-002** para VPN, **KB-006** para software).
- Formación obligatoria de seguridad TI (duración: 2 horas, online).
- Reunión de objetivos con el manager al final de la semana.

## Checklist de accesos (manager)

El manager debe abrir un ticket en soporte **3 días antes** de la incorporación solicitando:
- [ ] Cuenta corporativa de email
- [ ] Acceso VPN
- [ ] Acceso a repositorios de código (si aplica)
- [ ] Licencias de software del puesto
- [ ] Tarjeta de acceso físico
