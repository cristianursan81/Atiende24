# KB-006 · Licencias de software

**Categoría:** Software / Licencias

## ¿Cómo solicito una licencia de software?

1. Comprueba primero si el software ya está disponible en el **catálogo corporativo**:
   `https://intranet.empresa.com/software-catalog`.
2. Si está en el catálogo, pulsa **Instalar** y se instalará automáticamente en tu equipo en menos de 30 minutos.
3. Si no está en el catálogo, abre un ticket indicando:
   - Nombre y versión del software.
   - Justificación de negocio.
   - Presupuesto aproximado (si es de pago).

## Software disponible sin solicitud adicional

- Microsoft 365 (Word, Excel, PowerPoint, Teams, Outlook)
- Adobe Acrobat Reader
- Zoom
- Slack
- GitHub (cuenta corporativa)
- Visual Studio Code

## Instalación de software no autorizado

Queda **prohibida** la instalación de software no autorizado en equipos corporativos.
El incumplimiento puede derivar en medidas disciplinarias conforme a la política de seguridad TI.

## Renovación de licencias

Las licencias anuales se renuevan automáticamente. Si recibes un aviso de expiración,
contacta con soporte adjuntando el aviso para gestionar la renovación.
